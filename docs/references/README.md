## Rules for writers

1. Do not add a source that is not in this table. If you need one, raise it in the group first —
   it has to be checked and added to the paper's numbered list.
2. Do not renumber. The numbers are baked into the text and the figures' captions.
3. Cite a source where it supports a specific claim, not at the end of a paragraph as decoration.
